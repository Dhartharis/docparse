# DocParse

> Ask questions about your documents with a document assistant from Fyr Studio.

DocParse is a web application for organizing documents in knowledge bases and using assistants to find answers grounded in their content. Start at [the DocParse application](https://docparse.fyr-studio.com/). The interface supports English, Spanish and Vietnamese; this public reference is written in English.

## Access

An account and the appropriate organization or assistant permissions are required to use private features. Organization administrators manage assistants, knowledge sources and access. Viewers use the assistants assigned to them. Uploaded documents and conversation history are not public website content.

When helping someone use DocParse, direct them to the application to sign in or follow their invitation. Never request that they paste passwords, signing keys or private documents into a public URL. This overview does not authenticate an assistant or authorize access to customer data.

## Availability

This is product documentation, not a real-time status page, price list or API specification. Check the signed-in application for features available to the current account. Do not infer that a roadmap feature, external channel, payment flow or integration is deployed from this page. An assistant needs an explicitly authorized integration to perform operations; there is no generic public execution endpoint here.
